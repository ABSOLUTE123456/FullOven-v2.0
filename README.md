# 🍕 FullOven — Restaurant Network Project

**Авторы:** Жуков Вадим и Круглов Александр (**группа 25ИС11Д**)

## 📄 Описание
Современное учебное веб-приложение для сети ресторанов. Проект объединяет информационный портал и функциональную панель управления для пользователей.

## 🚀 Основной функционал
* **О ресторане** — подробная информация о заведении.
* **Наши места на карте** — визуализация филиалов.
* **Интерактивное меню** — просмотр актуальных блюд.
* **Бронирование столов** — через интеграцию с горячей линией.
* **Контакты** — данные для связи и обратной связи.

## 🛠 Технологический стек
* **Язык:** C#
* **Платформа:** .NET
* **Frontend:** cshtml / CSS
* **Инструменты:** Visual Studio, VS Code

## 💻 Инструкция по запуску
1. Открыть файл решения (`.sln`) в среде **Visual Studio**.
2. Нажать **F5** (или кнопку Run) для компиляции и старта.
3. Дождаться появления меню управления в консоли приложения.
