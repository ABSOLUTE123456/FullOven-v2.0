# FullOven — Сайт сети ресторанов
FullOven — это учебное веб-приложение, разработанное для автоматизации взаимодействия с клиентами сети ресторанов. Проект объединяет в себе информационный портал и функционал для взаимодействия с пользователем.

🚀 Функциональные возможности:
Проект реализует ключевые бизнес-процессы современного ресторана:
ℹ️ О ресторане: Подробная информация о бренде и концепции.
📍 Интерактивная карта: Визуализация расположения заведений.
📄 Электронное меню: Удобный просмотр доступных блюд и цен.
📞 Бронирование: Система связи с горячей линией для резерва столов.
📩 Контакты: Формы обратной связи и актуальные данные.
🛠 Технологический стек:
При разработке использовались современные инструменты и технологии:
Backend: C# / .NET
Frontend: HTML5 / CSS3
IDE: Visual Studio & VS Code
