# Release Notes — v1.0.0

## Новое
- Динамическое меню с категориями блюд
- Поиск по названию позиций
- Система онлайн-бронирования столиков
- Личный кабинет пользователя с историей заявок
- Профиль с возможностью загрузки аватарок
- Интерактивная страница "Наши заведения" с картами

## Безопасность и исправления
- Внедрено безопасное хеширование паролей пользователей (BCrypt)
- Добавлена валидация данных форм на стороне сервера
- Защита от загрузки вредоносных файлов под видом изображений
