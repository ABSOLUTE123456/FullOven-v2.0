# Как запустить FullOven

## Запуск из Visual Studio
1) Открыть решение проекта (.sln)
2) Нажать клавишу F5 для запуска в браузере

## Запуск из готовой сборки
1) Распаковать архив с релизом
2) Запустить исполняемый файл приложения polnuyaPetch.exe

## База данных
- В качестве СУБД используется SQLite (файл menu.db в корне)
