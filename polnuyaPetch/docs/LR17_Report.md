# Отчёт ЛР17 — Интеграция базы данных в FullOven

## Что сделано
- В веб-приложение успешно внедрен ORM-фреймворк Entity Framework Core.
- Локальное хранилище переведено на реляционную базу данных SQLite.
- В контексте данных `ApplicationDbContext` настроены три ключевые таблицы: `MenuItems`, `Reservations` и `Users`.
- Разработана и подключена к контексту интерактивная веб-форма онлайн-бронирования столов (обработчик `ReservationsModel`).
- Настроена автоматическая инициализация структуры и файлов базы данных при отправке формы.

## Как проверить
1) Запустить проект веб-приложения FullOven.
2) Перейти на страницу бронирования столов (`/Reservations`).
3) Заполнить форму бронирования (Имя, Телефон, Дата) и нажать кнопку отправки.
4) Убедиться, что выводится сообщение об успешном сохранении, а в корне проекта создается/обновляется файл базы данных `.db`.
