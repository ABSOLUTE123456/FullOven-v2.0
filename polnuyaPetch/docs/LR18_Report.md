# Отчёт ЛР18 — файл настроек config.json

## Что сделано
- Создана объектная модель настроек `AppConfig` и служебный сервис управления `ConfigService`.
- Реализована автоматическая генерация файла конфигурации `config.json` по умолчанию при первом запуске приложения, если файл отсутствует.
- Конфигурационные пути ко всем внутренним директориям (`data`, `logs`, `backups`, `exports`, `reports`) успешно вынесены из кода в JSON.
- На базе ASP.NET Core MVC разработана административная страница настроек (`/Home/Settings`), позволяющая динамически изменять параметры `StorageMode` и `AskOnStart` с последующим сохранением в файл.

## Как проверить
1) Удалить файл `config.json` из папки сборки и запустить веб-сайт ➡️ файл пересоздастся автоматически.
2) Перейти в верхнем меню по ссылке "Настройки (ЛР18)".
3) Изменить текущий режим хранения с Database на Memory, нажать "Сохранить настройки".
4) Открыть файл `config.json` и убедиться, что изменения зафиксированы в структуре документа.
